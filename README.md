# 敏捷开发与技术教学博客 - 开发需求说明书 (Agile & Tech Teaching Blog Specification)

## 1. 角色与核心目标

你现在是一位资深的前端架构师和技术布道师。请帮我从零搭建一个专注于“Agile/Scrum 教学与软件工程实践”的静态博客网站，部署在 GitHub Pages (自定义域名) 上。

## 2. 技术栈选择 (强制要求)

- **核心框架**：Astro (因为我后续会大量使用纯 HTML 格式来发布博客和教学内容，Astro 对混合 HTML 的渲染支持最完美)。
- **样式方案**：Tailwind CSS。
- **代码高亮**：Prism.js 或 Shiki，确保在渲染我的 HTML 代码块时能正确高亮 Java 和 Web 前端代码。

## 3. 核心机制要求 (HTML 内容支持)

由于我未来的博客和文档将以 `.html` 格式提供（或包含大量原生 HTML 标签）：

- 请在设计博客的内容渲染逻辑时，确保支持直接读取和渲染 HTML。
- 可以使用 Astro 的 `set:html` 指令来注入内容，或者配置 Astro 的路由使其能直接服务于 `src/pages/` 下的 `.html` 文件。
- 请在生成的脚手架中，提供一个清晰的示例：**演示我以后该如何添加一篇纯 HTML 格式的博客文章**。

## 4. 页面结构与路由规划

### 4.1 首页 (Home)

- **Hero Section**：
  - 标题：Aki's Agile Classroom & Tech Blog
  - 副标题：探索敏捷开发的价值观，分享 Java 底层架构设计，连接底层技术与商业产品价值。
- **板块入口**：提供跳转至“教学文档 (Docs)”和“最新博客 (Blog)”的入口。

### 4.2 教学与博客区 (Docs & Blog)

- **分类架构**：请设计一个能同时兼容“系列教学（如 Java 设计模式：Strategy, Observer, Factory）”和“日常杂谈（如 Scrum 价值观在课堂的运用）”的目录结构。
- **示例内容**：请在项目目录中，生成 2 篇使用 HTML 编写的测试文章，并确保它们能在前台正确展示（包括标题、发布时间、内容布局）。

### 4.3 关于作者 (About)

- **简介**：Zhong Tao (鍾 涛) - 即将开启 Product Engineer 生涯的敏捷践行者。拥有商学院 MBA 背景与丰富的 Java 讲师顾问经验。
- **履历展示**：突出从讲师到产品工程师的跨界视角。过往经历中包含实习，请在前端设计上留出能明确区分“实习 (Internship)”与“全职 (Full-time)”经历的 UI 标签。

## 5. UI/UX 与部署要求

- 必须包含全局的 Dark/Light Mode 切换。
- 文章详情页应控制最大阅读宽度 (如 `max-w-prose`)，确保我注入的 HTML 文本具有良好的排版可读性。
- **部署脚本**：生成适用于 GitHub Pages 发布环境的代码配置（提供 GitHub Actions 的 `.yml` 文件或构建命令指导）。

## 6. 开发执行步骤

1. **第一步：环境初始化**。输出 Astro 项目创建命令及目录结构规划供我确认。
2. **第二步：核心布局与组件开发**。
3. **第三步：HTML 内容集成测试**。编写具体的 HTML 博客渲染逻辑并生成测试数据。
4. **第四步：提供 GitHub Pages 部署方案**。
