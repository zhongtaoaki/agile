<h2>はじめに</h2>

<p>
  スクラムは、ソフトウェア開発だけでなく、教育現場でも強力なフレームワークです。
  本記事では、スクラムの5つの価値観を教室で実践する方法を紹介します。
</p>

<h2>スクラムの5つの価値観</h2>

<ul>
  <li><strong>コミットメント (Commitment)</strong> — 目標に全力でコミットする</li>
  <li><strong>フォーカス (Focus)</strong> — 優先度の高いことに集中する</li>
  <li><strong>オープン (Openness)</strong> — 課題や進捗を透明にする</li>
  <li><strong>尊重 (Respect)</strong> — お互いを個人として尊重する</li>
  <li><strong>勇気 (Courage)</strong> — 困難な問題に正直に向き合う勇気を持つ</li>
</ul>

<h2>実践1: デイリースクラムを「朝のサークル」として導入</h2>

<p>
  毎朝15分のスタンドアップミーティングを実施します。
  生徒それぞれが「昨日やったこと」「今日やること」「困っていること」を共有します。
</p>

<pre><code class="language-text">朝のサークル テンプレート
━━━━━━━━━━━━━━━━━━━━
昨日: [学んだこと・達成したこと]
今日: [取り組むこと]
課題: [助けが必要なこと]
━━━━━━━━━━━━━━━━━━━━</code></pre>

<h2>実践2: スプリントを「学習サイクル」として設定</h2>

<p>
  2週間を1スプリントとして、学習目標（スプリントゴール）を設定します。
  スプリントの終わりにはレビューとレトロスペクティブを行います。
</p>

<h2>実践3: バックログで学習の優先度を管理</h2>

<p>
  学ぶべき内容をバックログアイテムとして管理し、優先度順に並べます。
  これにより、「今何を学ぶべきか」が常に明確になります。
</p>

```javascript
// バックログアイテムの例 (JSON形式)
const sprintBacklog = [
  { id: 1, title: "Javaの基礎文法", points: 3, status: "done" },
  { id: 2, title: "オブジェクト指向の概念", points: 5, status: "in-progress" },
  { id: 3, title: "デザインパターン入門", points: 8, status: "todo" },
];
```

<h2>実践4: レトロスペクティブで継続的改善</h2>

<p>
  スプリントの最後に「良かったこと」「改善できること」「次に試すこと」を振り返ります。
  <em>KPT（Keep・Problem・Try）フォーマット</em>が特に効果的です。
</p>

<table>
  <thead>
    <tr>
      <th>Keep（続けること）</th>
      <th>Problem（問題）</th>
      <th>Try（試すこと）</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>朝のサークルは集中できる</td>
      <td>課題の提出が遅れがち</td>
      <td>ポモドーロタイマーを使う</td>
    </tr>
  </tbody>
</table>

<h2>実践5: 透明性を高めるかんばんボード</h2>

<p>
  物理的またはデジタルのかんばんボードを教室に設置します。
  「Todo → In Progress → Done」の流れで、全員の学習進捗を可視化します。
</p>

<h2>まとめ</h2>

<p>
  スクラムの価値観は、教育現場でも非常に有効です。
  小さな実験から始めて、チーム（クラス）の状況に合わせてカスタマイズしていきましょう。
  最も大切なのは「検査と適応」のマインドセットです。
</p>
